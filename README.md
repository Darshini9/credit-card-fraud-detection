# Credit Card Fraud Detection Analysis

# Overview
Analysis of 284,807 real credit card transactions to identify 
fraud patterns and support real-time detection strategies.

# Key Findings
- Overall fraud rate: 0.173% (492 fraudulent transactions)
- Night transactions (12–6am) show the highest fraud rate
- High-value transactions ($500–$2K) carry the greatest fraud risk
- Avg fraudulent transaction: $122.21 vs $88.29 legitimate
